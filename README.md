# 🎯 課題提出期限レーダー (Deadline Radar)

大学の後期課題の出し忘れを根本からゼロにするための提出期限管理システムです。  
ブラウザでリアルタイムのカウントダウンを確認できるほか、AI（Antigravity）チャットと直結しています。

---

## 🚀 使い方

### 1. ダッシュボードを開く
- **`start_dashboard.bat` をダブルクリック**するだけで、既定のブラウザで一発起動します。
- または、**`index.html`** をそのままブラウザにドラッグ＆ドロップしても開きます。
- （ブラウザのお気に入りバーにピン留めしておくのがおすすめです！）

---

## 🤖 AIチャット連携（チャットで頼むだけで完了）

このチャット画面で、日常会話のように話しかけるだけでAIが自動で課題データを更新・管理します。

| あなたのメッセージ例 | AIが行うこと |
| :--- | :--- |
| **「天体物理の課題、来週月曜17時までって登録して」** | 新しい課題を自動登録＆締切順に並び替え |
| **「数値計算の課題出したよ」** | ステータスを自動で「提出完了」に変更 |
| **「今週締め切りの課題、何がある？」** | 近い順にリストアップして教えてくれる |
| **「国際関係論の締切、金曜23:59に延びたから変更して」** | 締切日時を自動修正 |
| **「量子力学の課題、どこまでやってたっけ？」** | メモや関連ファイル（演習PDF等）を確認 |

---

## 🔥 出し忘れを防ぐ 3大機能

### ① 視覚的なカウントダウン警告
- 🚨 **24時間以内**: 赤色パルス点滅で「あと〇時間〇分」と強力に警告
- ⚠️ **3日以内**: 黄色/オレンジ色で今週中の提出をリマインド
- 🔵 **余裕あり**: 残り日数を表示
- 💀 **締切超過**: 期限を過ぎた未提出を紫色の警告バッジで表示

### ② スマホ・カレンダー通知（Googleカレンダー / iPhone連携）
各課題の右側にある **「📅 カレンダー」ボタン** を押すと、`.ics` ファイルがダウンロードされます。
- ダブルクリックして Googleカレンダー や iPhone/Macカレンダー、Outlook に追加すると、**「前日」と「2時間前」にスマホへ自動プッシュ通知** が届くようになります。

### ③ 科目別色分け＆ワンクリック完了
- 理学部第一部の各科目（物性論、統計力学、量子力学、天体物理学、原子核物理、数値計算、実験、国際関係論、データサイエンス等）ごとにカラーバッジで整理。
- 科目ボタンを押すだけでその授業の課題だけに絞り込めます。
- 提出したらボタンをポチッと押すだけで「✅ 提出完了」に切り替わります。
